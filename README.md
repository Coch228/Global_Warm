# Global_Warm


#Факторий
Факторий - это будет список фактов о конкретной теме (в моём случае о глобальном потеплении). В этом списке будет 50 фактов о глобальном потеплении.

#Решебник
Решебник - это будет список фактов о решении конкретной темы (в моём случае о глобальном потеплении). В этом списке будет 50 фактов о решении проблем связанных с глобальным потеплением.

#Виктрина
из 100 фактов сделать викторину из 10 вопросов
